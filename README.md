# Advanced TypeScript Assignment - 1

This repository contains the solutions for the TypeScript assignment from Programming Hero. It demonstrates advanced concepts of TypeScript, including strict type safety, type narrowing, generics, and Object-Oriented Programming (OOP).

**Technical Blogs:**
  - `blog-1.md`: A detailed article explaining why `unknown` is safer than `any`.
  - `blog-2.md`: A guide on writing DRY (Don't Repeat Yourself) code using TypeScript Generics.
